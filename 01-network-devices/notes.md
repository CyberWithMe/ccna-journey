## What is a Network?
A computer network is a digital telecommunication channel that allows nodes to share resouces. 

## Types of Nodes:
# 1) Router
        - Routers have fewer network interaces than switches
        - Routers are used to provide connectivity within LANs
        - Routers are used to send data over the internet.
# 2) Switch
        - Swtiches have many network interfaces and ports. Typically 24+
        - Switches are used to forward traffic within a Local Area Network (LAN)
        - Swtiches are not used to provide connectivity between LANs/over the internet. 
# 3) Firewall
        - Network security devices that control traffic entering and exiting the network by configuring rules.
        - Can be placed inside or outside the network
        - Can be knows as 'Next-Generation Firewalls' (NGFW) when they include more modern and advanced filtering capabilities.
        - There are:
                - Network firewalls
                - Host based firewalls
                - Web application firewalls
                - Software firewalls. 
# 4) Server
        - A server is a device that provides functions or services for a client. 
        - Clients can act as servers to share resources with other clients.
                - Example: Phone A acts as a server when sending a video to Phone B. Phone B is the client. 
# 5) Client
        - A client is a device that accesses services made available by a server.
